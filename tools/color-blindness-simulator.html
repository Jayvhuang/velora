Color Blindness Simulator

See how a color appears under common types of color vision deficiency: protanopia, deuteranopia, tritanopia.

Open the free Color Blindness Simulator →

The Color Blindness Simulator shows how a single color looks under protanopia, deuteranopia, and tritanopia.

It is an educational approximation to help you reason about accessibility, not a clinically accurate view of any person's vision.

Frequently asked questions

Which types are simulated?

Protanopia (red-blind), deuteranopia (green-blind), and tritanopia (blue-blind).

Is this clinically accurate?

No. It uses a standard simulation matrix and is an educational approximation only.

Should I rely on it for accessibility?

Use it alongside the Contrast Checker and WCAG guidelines for real auditing.
